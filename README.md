# Lab-4
# Практична робота: Розділ 1 (Задачі 6, 7, 8, 9)

**Тема:** Базові оператори, логічні вирази, форматування виведення та порівняння чисел з рухомою комою в C++.

## Виконані завдання

1. **Задача 6 (`task_6.cpp` — Lab 1.6.1):** побудова складного булевого виразу з використанням операторів порівняння та логічних операторів `&&`, `||`.
2. **Задача 7 (`task_7.cpp` — Lab 1.7.1):** форматування виведення дійсних чисел за допомогою маніпуляторів `fixed` та `setprecision` з бібліотеки `<iomanip>`.
3. **Задача 8 (`task_8.cpp` — Lab 1.7.2):** порівняння чисел з рухомою комою через модуль різниці з заданою точністю ($\varepsilon = 0.000001$).
4. **Задача 9 (`task_9.cpp` — Lab 1.7.3):** зчитування чотирьох чисел, перевірка їхньої належності діапазону `[1; 255]` та формування рядка IP-адреси.
